# Tenora brand assets

This directory preserves the supplied source artwork and visual reference sheet.

- `TenoraAppIconSource.png` is the original app-icon artwork.
- `TenoraBrandSheet.png` documents the logo system, palette, typography direction, and usage examples.

The shipping Xcode app icon is a centered, non-transparent 1024 × 1024 derivative in `Tenora/Resources/Assets.xcassets/AppIcon.appiconset`. Application colors are semantic asset-catalog entries based on the documented palette:

- Navy: `#0F1F3A`
- Blue: `#3A6DFF`
- Purple: `#7B5CFF`
- Lavender: `#B59DFF`
- Off-white: `#F5F6F8`

Tenora currently uses the native iOS system typeface to retain first-class Dynamic Type support. Space Grotesk can be evaluated later when onboarding and the broader visual system are implemented.
