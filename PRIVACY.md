# Tenora Privacy Policy

Last updated: September 30, 2026

Tenora is designed to keep its core task and attention data on the user's device. Tasks, notes, schedules, working hours, recovery context, and preference settings are stored locally by the app.

## Calendar access

With permission, Tenora reads events from calendars available through Apple Calendar to calculate availability and show upcoming events. Calendar information is processed on-device and is not copied into Tenora's task database or included in data exports.

## Notifications

Tenora schedules local notifications on the device. Apple controls notification permission and delivery.

## Data sharing

The optional ChatGPT agent bridge is disabled in the initial release. If a future release enables an external sharing feature, it will require explicit opt-in and will describe the selected data before sharing begins.

## Data control

Users can export their locally stored Tenora data or delete it from Data & Privacy in the app. Deleting Tenora data does not change calendar or notification permissions managed by iOS.

## Support

Questions and support requests can be submitted through the [Tenora GitHub repository](https://github.com/mjdriscoll94/tenora/issues).
